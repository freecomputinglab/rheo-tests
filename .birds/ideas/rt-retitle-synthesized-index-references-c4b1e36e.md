## The rheo change

`auto_index` (default on) mints a landing page for a content directory that
has no `index.typ` and no `<dirname>.typ`, at the notional path
`<dir>/index.typ`. Its title is derived from the file STEM, which is `index`,
so every such page is currently titled "Index".

rheo bird `rh-title-a-synthesized-index-by-directory-0b69f6c4` (label
`fix-auto-index-title`) changes that to the prettified PARENT DIRECTORY name:
`guide/` gives "Guide", and a directory named `01-intro/` gives "Intro" (a
leading numeric order prefix is stripped, `-`/`_` become spaces, each word is
title-cased). A REAL, author-written `index.typ` is explicitly NOT affected —
it stays "Index" and the author overrides it with `#set document(title: ...)`.
You are not implementing any of that; do not edit anything under
`/home/lox/code/_fcl/rheo`.
